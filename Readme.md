# HASC Notes 📚

> Notes, examples, practice code, and mini-projects created while teaching **HASC (Hartron Advanced Skill Center)** web development.

This repository is a central collection of classroom material for learning **HTML, CSS, JavaScript, DOM manipulation, and Data Structures & Algorithms (DSA)** through practical examples and exercises.

The material is organized by topic and, where useful, by batch so students can quickly find the code covered in class.

## 🛠️ Learning Approach

The repository follows a practical, code-first approach:

**Concept → Example → Practice → Mini Project → Problem Solving**

The goal is to learn web development by writing and modifying code rather than collecting another pile of notes nobody opens after the exam.

---

## 🚀 Recommended Learning Order

```text
HTML
  ↓
CSS
  ↓
JavaScript Basics
  ↓
Arrays / Objects / Functions
  ↓
DOM Manipulation
  ↓
Mini Projects
  ↓
DSA & Problem Solving
```
